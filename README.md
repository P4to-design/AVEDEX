# AVEDEX Versão Beta

Nessa versão temos na estrutura do código:

- Menu que repete com um while;
- Ações separadas em if;
- Três flags para repetição e verificação;
- uma ave já cadastrada (Carcará);
- a possibilidade de cadastrar uma  ave nova;
